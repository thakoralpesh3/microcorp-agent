## 3. Production Code Patterns & Architecture Examples

### A. The Resilient Client Factory (TypeScript/Node.js)
Don't instantiate the client globally. Use a factory pattern to handle timeouts and retries automatically.

```typescript
import { GenieClient } from '@genie-ai/sdk';

const createGenieClient = (apiKey: string) => {
  return new GenieClient({
    apiKey,
    timeout: 30000,
    retryConfig: {
      attempts: 3,
      backoff: (attempt) => Math.pow(2, attempt) * 100,
    },
  });
};

// Usage
const genie = createGenieClient(process.env.GENIE_API_KEY);
```

### B. Streaming Response Pattern (React/Frontend)
Implement a robust state machine for streaming interfaces to ensure UI consistency.

```tsx
const useGenieStream = (prompt: string) => {
  const [response, setResponse] = useState('');
  
  const handleGenerate = async () => {
    const stream = await genie.generateStream({ prompt });
    
    for await (const chunk of stream) {
      setResponse((prev) => prev + chunk.text);
    }
  };
  
  return { response, handleGenerate };
};
```

## 4. Common Anti-Patterns & Gotchas to Avoid

1.  **The "Blob" Prompt:** Passing your entire database schema as a single system prompt string. 
    *   *Fix:* Use schema-specific sub-schemas or JSON-based metadata definitions.
2.  **Lack of Token Budgeting:** Assuming every request fits in the token window. 
    *   *Fix:* Implement a "Sliding Window" buffer that truncates the oldest history once it hits 80% of the token limit.
3.  **Silent Failure:** Ignoring 429 (Rate Limit) errors.
    *   *Fix:* Always wrap calls in a middleware that observes the `Retry-After` header.
