## Production Code Patterns & Architecture

### 1. Secure JWT Token Factory (`core/security.py`)
```python
from datetime import datetime, timedelta
from jose import jwt

SECRET_KEY = "your-super-secret-key"
ALGORITHM = "HS256"

def create_access_token(data: dict):
    to_encode = data.copy()
    expire = datetime.utcnow() + timedelta(minutes=30)
    to_encode.update({"exp": expire})
    return jwt.encode(to_encode, SECRET_KEY, algorithm=ALGORITHM)
```

### 2. Dependency-Injected Auth (`api/deps.py`)
```python
from fastapi import Depends, HTTPException, status
from fastapi.security import OAuth2PasswordBearer

oauth2_scheme = OAuth2PasswordBearer(tokenUrl="login")

async def get_current_user(token: str = Depends(oauth2_scheme)):
    # Logic to decode JWT and query DB
    try:
        user = verify_token(token)
        if not user: raise HTTPException(status_code=status.HTTP_401_UNAUTHORIZED)
        return user
    except Exception:
        raise HTTPException(status_code=401)
```

## Common Anti-Patterns & Gotchas

*   **Blocking I/O:** Using standard `requests` or blocking DB drivers inside `async def` routes. **Fix:** Always use `httpx` and `asyncpg`.
*   **Hardcoded Secrets:** Storing DB credentials or keys in source code. **Fix:** Use `pydantic-settings` to load from `.env` files.
*   **The "Fat" Controller:** Putting business logic directly in the route handler. **Fix:** Abstract logic into `services/` or `crud/` layers.
*   **JWT Revocation:** Ignoring that JWTs are stateless. **Fix:** Implement a "blacklist" in Redis if you require instant user banning.

## Performance & Optimization Tips

1.  **Gunicorn Workers:** Run your FastAPI app with `gunicorn -k uvicorn.workers.UvicornWorker` to utilize multi-core architecture.
2.  **Connection Pooling:** Configure SQLAlchemy's `AsyncEngine` with `pool_size` and `max_overflow` to handle database traffic spikes without latency.
3.  **Caching:** Integrate Redis for expensive compute tasks or frequent DB lookups using `aioredis`.
4.  **Schema Projection:** Use Pydantic's `response_model_exclude_unset` to reduce payload size and hide internal database fields.
