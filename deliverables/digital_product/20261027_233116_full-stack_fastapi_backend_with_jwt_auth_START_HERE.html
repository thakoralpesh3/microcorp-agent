from pydantic_settings import BaseSettings, SettingsConfigDict

class Settings(BaseSettings):
    PROJECT_NAME: str = "MicroCorp AI Enterprise Backend"
    API_V1_STR: str = "/api/v1"
    
    # Database
    POSTGRES_SERVER: str
    POSTGRES_USER: str
    POSTGRES_PASSWORD: str
    POSTGRES_DB: str

    # Security / JWT
    SECRET_KEY: str
    ALGORITHM: str = "HS256"
    ACCESS_TOKEN_EXPIRE_MINUTES: int = 30

    model_config = SettingsConfigDict(
        env_file=".env",
        env_file_encoding="utf-8",
        case_sensitive=True
    )

    def __init__(self, **kwargs):
        super().__init__(**kwargs)
        if not self.DATABASE_URL:
            self.DATABASE_URL = (
                f"postgresql+asyncpg://{self.POSTGRES_USER}:"
                f"{self.POSTGRES_PASSWORD}@{self.POSTGRES_SERVER}/{self.POSTGRES_DB}"
            )

settings = Settings()

from typing import AsyncGenerator
from sqlalchemy.ext.asyncio import AsyncSession, create_async_engine
from sqlalchemy.orm import sessionmaker
from app.core.config import settings

engine = create_async_engine(
    settings.DATABASE_URL,
    echo=False,
    future=True,
    pool_size=20,
    max_overflow=10,
)

AsyncSessionLocal = sessionmaker(
    bind=engine,
    class_=AsyncSession,
    expire_on_commit=False,
    autocommit=False,
    autoflush=False,
)

async def get_db() -> AsyncGenerator[AsyncSession, None]:
    """Dependency for obtaining asynchronous database sessions."""
    async with AsyncSessionLocal() as session:
        try:
            yield session
            await session.commit()
        except Exception:
            await session.rollback()
            raise
        finally:
            await session.close()

from datetime import datetime, timedelta
from typing import Any, Union
from jose import jwt
from passlib.context import CryptContext
from app.core.config import settings

pwd_context = CryptContext(schemes=["bcrypt"], deprecated="auto")

def verify_password(plain_password: str, hashed_password: str) -> bool:
    return pwd_context.verify(plain_password, hashed_password)

def get_password_hash(password: str) -> str:
    return pwd_context.hash(password)

def create_access_token(subject: Union[str, Any], expires_delta: timedelta = None) -> str:
    if expires_delta:
        expire = datetime.utcnow() + expires_delta
    else:
        expire = datetime.utcnow() + timedelta(
            minutes=settings.ACCESS_TOKEN_EXPIRE_MINUTES
        )
    to_encode = {"exp": expire, "sub": str(subject)}
    encoded_jwt = jwt.encode(to_encode, settings.SECRET_KEY, algorithm=settings.ALGORITHM)
    return encoded_jwt

4. ## Common Anti-Patterns & Gotchas to Avoid

Engineers transitioning to async FastAPI often run into subtle blocking bugs. Avoid these traps:

  • ❌ Anti-Pattern: Blocking I/O inside Async Endpoints
Why:* Calling synchronous libraries (like standard requests, blocking SQL drivers, or heavy CPU-bound loops) inside an async def route starves the event loop, freezing all concurrent requests. ✅ Fix:* Use asyncpg, httpx, or offload blocking operations using starlette.concurrency.run_in_threadpool.
  • ❌ Anti-Pattern: Hardcoding Secrets & Configuration
Why:* Storing database credentials or JWT secret keys in code repository files leads to immediate security compromises. ✅ Fix:* Always utilize Pydantic BaseSettings reading exclusively from environment variables.
  • ❌ Anti-Pattern: Ignoring Database Connection Pool Exhaustion
Why:* Opening a new database engine per request or failing to close sessions correctly leads to connection leaks and PostgreSQL crashes (FATAL: sorry, too many clients already). ✅ Fix:* Use a singleton engine instance coupled with dependency injection yielding session generators (get_db).

5. ## Performance & Optimization Tips

Maximize throughput and minimize latency with these architectural adjustments:

1. Uvicorn Worker Scaling: In production, run Uvicorn behind a process manager or configure multiple workers (--workers 4 or set to CPU_COUNT * 2 + 1) to fully saturate multi-core cloud instances.

2. Response Compression: Integrate GZipMiddleware to compress payloads larger than 1KB, drastically reducing network transfer times for mobile and web clients.

3. Database Indexing & Query Profiling: Leverage SQLAlchemy statement profiling and ensure foreign keys and frequently filtered columns (e.g., email, status) have active B-tree indexes.

4. Caching Layer: Place Redis in front of complex analytical queries or expensive external API calls using decorators or dependency caching.
