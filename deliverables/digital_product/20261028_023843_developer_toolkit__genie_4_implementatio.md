## 3. Production Code Patterns & Architecture Examples

### A. The "Chain-of-Thought" Wrapper Pattern
Use this pattern to ensure consistent reasoning output across your application services.

```typescript
// @file: services/GenieWrapper.ts
export interface GenieRequest {
  prompt: string;
  systemInstruction: string;
  metadata?: Record<string, any>;
}

export const executeGenieChain = async (request: GenieRequest) => {
  const response = await fetch('/api/v4/genie-stream', {
    method: 'POST',
    body: JSON.stringify({
      ...request,
      chain_of_thought: true,
      max_tokens: 1024
    })
  });

  if (!response.body) throw new Error("Stream connection failed");
  return response.body.getReader();
};
```

## 4. Common Anti-Patterns & Gotchas

*   **The "Context Dump" Mistake:** Never pass raw, unfiltered database logs into the `systemInstruction` field. This triggers hallucination and increases latency. Always summarize logs server-side first.
*   **Ignoring Token Costs:** Avoid sending the full history in every request. Use a rolling window (e.g., last 10 messages) to maintain a cost-efficient balance.
*   **Hard-coded Secrets:** Never bake your `GENIE_API_KEY` into the client-side bundle. Always proxy requests through an internal backend service.

## 5. Performance & Optimization Tips

1.  **Semantic Caching:** If your users ask repetitive questions, store the request/response hash in a vector database (e.g., Pinecone). Return the cached result to save API credits and provide instant responses.
2.  **Streaming UI:** Always implement **Server-Sent Events (SSE)** for the UI. Showing a "typing" effect creates a better UX than waiting for a full 5-second model inference.
3.  **Request Parallelization:** If performing multiple tasks (e.g., Summary + Sentiment Analysis), fire these as concurrent asynchronous promises rather than awaiting them in a serial chain.
