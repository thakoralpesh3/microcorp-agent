### 3. Production Code Patterns & Architecture

#### A. Secure JWT Implementation (`auth.py`)
```python
from jose import jwt
from datetime import datetime, timedelta

SECRET_KEY = "SUPER_SECRET_KEY_CHANGE_ME"
ALGORITHM = "HS256"

def create_access_token(data: dict):
    to_encode = data.copy()
    expire = datetime.utcnow() + timedelta(minutes=30)
    to_encode.update({"exp": expire})
    return jwt.encode(to_encode, SECRET_KEY, algorithm=ALGORITHM)
```

#### B. Production Dockerfile (Multi-Stage)
```dockerfile
# Stage 1: Builder
FROM python:3.11-slim as builder
RUN pip install poetry
COPY pyproject.toml .
RUN poetry export -f requirements.txt > requirements.txt

# Stage 2: Final
FROM python:3.11-slim
WORKDIR /app
COPY --from=builder /requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt
COPY . .
CMD ["uvicorn", "main:app", "--host", "0.0.0.0", "--port", "8000"]
```

### 4. Common Anti-Patterns & Gotchas

*   **Blocking IO:** Never use synchronous database drivers (like standard `psycopg2`) in FastAPI. Always use `asyncpg`. A single blocked thread kills your concurrency.
*   **Hardcoded Secrets:** Never put keys in your code. Use a `.env` file and a `pydantic-settings` class to load configurations.
*   **Massive Models:** Do not pass DB models directly to response schemas. Create separate Pydantic `BaseModel` classes to prevent leaking internal database IDs or passwords.
*   **Unbounded CORS:** Setting `allow_origins=["*"]` is a security violation. Explicitly whitelist your frontend domains.

### 5. Performance & Optimization Tips

1.  **Gunicorn + Uvicorn Workers:** In production, do not run `uvicorn` directly. Use `gunicorn` as the process manager to spin up multiple worker processes based on your CPU core count.
2.  **Connection Pooling:** Always use an asynchronous connection pool (like `async_sessionmaker` in SQLAlchemy) to prevent database connection exhaustion.
3.  **Caching:** Implement `Redis` for high-frequency endpoint caching to reduce DB load.
4.  **JSON Serialization:** Use `orjson` as your serialization engine (FastAPI supports this natively) to increase response speed by 30-50% for complex JSON payloads.
