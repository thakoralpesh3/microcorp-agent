## 2. Quick Start & Core Concepts
Blender 5.3 treats Gaussian Splats as a distinct geometry primitive. Unlike traditional mesh workflows, Splats rely on **SH (Spherical Harmonics)** for lighting and **covariance matrices** for spatial distribution.

| Concept | Definition | Blender 5.3 Property |
| :--- | :--- | :--- |
| **Splat** | A semi-transparent 3D Gaussian ellipsoid | `geometry.splat` |
| **SH Degree** | Frequency of view-dependency | `data.sh_order` (0–3) |
| **Opac** | Alpha-threshold for depth-culling | `material.opacity_clip` |
| **Covariance** | The "shape" of the splat (rotation/scale) | `transform.covariance` |

**Initialization command (CLI):**
```bash
blender --background --python scripts/import_splat.py -- --path ./assets/scan_01.ply --optimize
```

## 3. Production Code Patterns & Architecture
Use this Python snippet to programmatically ingest `.ply` files into your 5.3 scene without manual UI interaction.

### The Import Wrapper (`import_splat.py`)
```python
import bpy
import os

def import_gaussian_splat(file_path):
    """
    Standardized entry point for splat ingestion.
    Enforces scene units and camera sync.
    """
    if not os.path.exists(file_path):
        raise FileNotFoundError(f"Source file missing: {file_path}. Ensure file path is absolute.")

    # Import via standard operator with optimized defaults
    bpy.ops.import_scene.gaussian_splat(filepath=file_path, 
                                        sh_degree=3, 
                                        render_mode='ACCURATE')
    
    obj = bpy.context.selected_objects[0]
    obj.name = "Splat_Master_Reference"
    return obj

# Usage Example
```

## 4. Common Anti-Patterns & Gotchas
*   **The "Mesh-Conversion" Trap:** Avoid converting Splats to meshes using Marching Cubes. You lose the view-dependent reflections and performance. Keep them as point-based primitives.
*   **Scale Mismatch:** Splats often export in *Centimeters* while Blender defaults to *Meters*. Always normalize your transformation matrix by 0.01 during import.
*   **The Depth Sorting Bug:** If your splats appear "flickery," it is an alpha-sorting issue. Ensure `Display > Transparency` is set to `Sorted` in the viewport properties.

## 5. Performance & Optimization Tips
*   **Frustum Culling:** When rendering scenes with >5M splats, enable `Viewport Culling` in the Object Data properties.
*   **SH Truncation:** For background assets, force `SH Degree` to `0` or `1`. This significantly reduces VRAM usage without noticeable quality loss in distant environments.
*   **Lazy Loading:** If building a massive set, use a **Bounding Box Proxy** for the viewport and only load the full splat cloud at render-time using a driver-switched display mode.
